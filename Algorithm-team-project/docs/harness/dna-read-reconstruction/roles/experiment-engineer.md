# Experiment Engineer Role

## Responsibility

Maintain the Python testing and benchmark environment.

## Required Work

- Generate reference genome, my genome, and noisy reads.
- Run all algorithms on identical datasets.
- Build C++ algorithms before benchmark runs.
- Save CSV results under `experiments/results/`.
- Save graphs under `experiments/figures/`.
- Keep benchmark commands documented.

## Quality Bar

Final metrics must compare reconstructed output against the gold standard `my genome`.
